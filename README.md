# MVC Movie Rental App

A movie rental web application built with **ASP.NET MVC**, **C#**, **Entity Framework**, and **SQL Server**. The project demonstrates a complete MVC-based web application with authentication, data validation, and database-driven functionality.

## Overview

**MVCMovieRentalApp** is a movie rental management system that allows users to work with customer and movie-related data through a clean MVC architecture. The project uses **ASP.NET Identity** for authentication and **Entity Framework Code First** for data access and database migration support.

## Features

* ASP.NET MVC architecture
* Customer management
* Movie and genre management
* Membership-based customer details
* User authentication and account management
* Entity Framework Code First
* SQL Server database integration
* Validation using data annotations
* Bootstrap-based UI
* Clean separation of models, views, and controllers

## Technology Stack

* **C#**
* **ASP.NET MVC 5**
* **Entity Framework 6**
* **ASP.NET Identity**
* **OWIN**
* **SQL Server / LocalDB**
* **HTML, CSS, JavaScript**
* **Bootstrap**
* **jQuery**

## Project Structure

* `Controllers/` — MVC controllers for app functionality
* `Models/` — domain models such as customer, genre, and membership-related entities
* `Views/` — Razor views for the UI
* `Migrations/` — Entity Framework migrations
* `App_Start/` — route, bundle, filter, and authentication configuration

## Getting Started

### Prerequisites

* Visual Studio
* .NET Framework support
* SQL Server / LocalDB

### Run the Project

1. Clone the repository.
2. Open `MVCMovieRentalApp.sln` in Visual Studio.
3. Restore NuGet packages.
4. Build the solution.
5. Run the application using IIS Express.

## Purpose

This project was created to demonstrate practical knowledge of **ASP.NET MVC**, **Entity Framework**, **authentication**, and **database-driven web application development**.
